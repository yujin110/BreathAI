# 근거 외 생성 원인·수정 및 참고용 20문항 — 2026-10-31

이 기록에서 남았던 5건은 이후 추가 수정했다. 최신 결과는
[남은 5건 원인·수정·재검증](remaining-five-fix-20261031.md)을 참고한다. 이전 결과 원문은 보존한다.

## 확인한 원인

1. KB가 비어 있어도 인용 표현 예시가 전달됐다. 빈 근거를 고객센터 문의로 우회하라는 지시도 있었다.
2. system은 2~4문장, user 프롬프트는 5~9문장으로 충돌했고, 검증기는 80자 미만을 실패시켜 불필요한 확장을 유도했다.
3. Refine에 역무실 인터폰·1577-1234 예시를 하드코딩하고, 연락처·시간을 보강하도록 지시했다. 실제 질문의 허용 근거와 무관하게 답변에 들어갈 수 있었다.
4. 재시도는 이전 답변의 내용·분량 유지를 요구했다. fallback도 검증 실패한 자유 본문을 그대로 감싸 반환했다.
5. 기존 검증은 브랜드·사과·길이 위주였다. LLM의 사실 문장을 최종 출력에서 근거와 강제로 연결하지 않았다. 자기 Judge 점수로도 이 문제를 잡지 못했다.

## 수정 방식

회귀 테스트는 99개 실행하여 98개 통과, 1개 건너뜀이다. 로그는 `tmp/llama-grounding-fix-tests-final.log`다.
근거 없는 인용·가짜 ID·임의 본문·수치 충돌·문서 지시문·가짜 계약·목록 문맥·실패 fallback·긴급 고정 안내 회귀를 포함한다.

답변 생성에서 Llama의 역할을 **허용 근거 답변 본문의 ID 선택**으로 제한했다. 최종 사실 본문은 선택된 KB 원문 또는 명시적으로 승인된 고정 정보만 렌더링하고, 기존 prefix/suffix를 붙인다. 키워드와 질문은 선택에만 사용하며 새로운 사실의 출처로 취급하지 않는다.
- 실제 전달 가능한 근거/승인된 고정 정보가 없으면 LLM을 호출하지 않고 확인 불가 고정 안내를 반환한다.
- 존재하지 않는 ID, 잘못된 선택 JSON, 불명확한 선택은 확인 불가로 처리한다. 모델이 JSON에 임의의 answer 필드를 추가해도 렌더링하지 않는다.
- Refine의 이전 답변은 사실 출처에서 제외한다. 이전 전화번호·시간·약속은 제공 근거에 없다면 출력할 경로가 없다.
- 내용 늘리기·고정 전화번호 보강·검증 실패한 이전 본문 보존 지시를 제거했다. 실패 fallback은 자유 본문을 재사용하지 않는다.
- 임시 JSON 근거 계약에는 프로세스 내부 서명을 붙여 문서/이전 답변에 삽입된 가짜 계약으로 승인 정보를 대체할 수 없도록 했다.
- 동일 문장 구조에서 수치가 충돌하면 확정을 보류한다. 이는 제한적인 수치 충돌 검사이며 일반 의미 충돌 전체를 검출하지는 않는다.
- 명백한 문서 지시문을 근거 단위에서 제외한다. 이 제한된 패턴 필터가 일반적인 문서 오염·프롬프트 주입 방어를 입증하지는 않는다.
- KB가 없는 FAQ 합성 단계의 answerDraft도 검증되지 않은 모델 답변 대신 확인 불가 초안으로 저장한다. 질문/동의어 생성과 JSON 스키마는 유지한다.
- 답변 양식의 문체 지침과 사실 정보를 분리했다. 고정 사실은 approved_facts, 승인 연락처는 default_contacts로 명시한다. EMERGENCY의 기존 안전 안내를 approved_facts에 옮겼다.

자유로운 의역보다 사실 출처를 우선하는 보수적인 방식이다. 원문 문체·목록·오탈자가 남을 수 있으며, 문단이 길면 답변도 길어진다. 잘못되거나 오래된 KB 자체를 참으로 만들어 주지는 않는다. API/DB의 answerDraft 문자열 등 기존 필드는 유지한다.

## 참고용 20문항 실행

- 기존 KB 스냅샷에서 가져온 10문항 + 합성 통제 사례 10문항. 기존 20문항의 답변/점수 재사용이 아니다.
- 기존 KB 스냅샷은 1,093건 중 선택했다. 현재 공식 정책과의 최신성 검증은 수행하지 않았다. 질문을 KB에 직접 연결했으므로 실제 검색기 성능 평가가 아니다.
- 모델은 공식 Llama 3.1 8B Instruct, 리비전 0e9e39f249a16976918f6564b8830bc894c89659. 로컬 RTX 2060 6GB, NF4 4bit, FP16, CPU 오프로딩.
- 근거 ID 선택은 temperature=0, max_new_tokens=160. 20문항 처리 중 실제 모델 호출은 17회, 근거 없음·명확한 수치 충돌 등 3건은 고정 분기로 처리했다.
- 첫 실행에서 문장 분할로 수수료 목록 제목만 선택하는 누락이 발견됐다. 답변 본문 단위와 원래 FAQ 질문 메타데이터를 유지한 후 같은 20문항을 재실행했다.
- 모델 실행 뒤 추가한 잘못된 계약 형식/실패 fallback 보강은 단위 테스트로 확인했다. 저장된 모델 선택을 최종 코드로 재생해 20개 출력이 일치함을 확인했다.
