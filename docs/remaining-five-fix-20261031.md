## 결과

## 보완 범위와 제한

- 근거 ID 검증과 원문·승인 고정 양식 조립은 유지한다. 새로운 정책·요금·연락처를 자유 생성하지 않는다.
- 정확 FAQ 회복은 관련 단위가 하나이고 질문이 충분히 구체적이며 정확히 일치할 때만 적용한다. 여러 근거 또는 다른 질문을 임의로 선택하지 않는다.
- 요금 회복은 대상 이름이 맞고 단일 요금이 명시되며 조건·할인·주말 등 단서가 없는 좁은 경우다. 다른 대상/조건부 요금/여러 근거에는 강제로 답하지 않는다.
- 잘못된 JSON이나 알 수 없는 ID에는 이 회복 규칙을 적용하지 않는다. 충돌 보류도 유지한다.
- 기한 누락 안내는 명시적인 기한 질문과 제한된 표현을 다룬다. 모든 질문의 의미적 완전성을 판정하는 기능은 아니다.
- 원문에 실제 URL이 있으면 보존하고 위치 참조를 주소로 바꾼다. 주소가 없으면 문구만 제거한다. menuIdx로 임의 경로를 만들지 않는다.
- 해당 두 KB의 실제 요금 버튼 URL은 복원하지 못했다. 이를 제공하려면 운영자가 확인한 주소/연결 정보를 KB 또는 UI 데이터에 추가해야 한다.
- 문서 오염 방어, 모든 유사 질문, 실제 Top-5 검색·BE/DB·서버 배포를 이 회귀 검사만으로 보장하지 않는다. Qwen 가중치는 계속 보관했다.
