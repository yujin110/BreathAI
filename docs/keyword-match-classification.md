# 키워드 매칭률 기반 답변 분류

2026-11-01 사용자 확정 정책을 적용한다.

| 매칭률(%) | 분류 | logType |
| --- | --- | --- |
| 0 이상 25 미만 | 미답변 | UNANSWER |
| 25 이상 75 미만 | 오답변/저품질 | LOW_QUALITY |
| 75 이상 100 이하 | 답변 | CORRECT |

이전 질의응답 자료에는 미답변을 '25% 미만'과 '25% 이하'로 혼용한다.
정확히 25%는 선택질문(25~75%) 구간에 포함하고, 정확히 75%는 '75% 이상 답변'에 포함한다.

여기서 분류는 매칭률에 따른 업무상 분류다. 답변 내용의 사실성을 별도 평가한 결과는 아니다.

## 기존 분석 업로드

필수 열은 `번호`, `질문`, `날짜`다. CSV는 UTF-8(BOM 포함)/CP949를 자동으로 읽으며 XLSX도 지원한다.
분류 우선순위는 유효한 명시적 `logType` → `keywordMatchPercent` → `ai_percent` → 기존 미답변 전용 입력의 `UNANSWER`다.
빈 문자열인 logType은 생략과 같으며, 공백만 있는 logType이나 잘못된 분류값은 기존처럼 오류다.

`keywordMatchPercent`는 확정된 0~100 백분율이다. `30`, `30.0`, `30%`를 허용한다.
`0.75`는 0.75%다. 0~1 비율로 자동 추정하지 않는다.
`ai_percent`는 0~10000의 정수이며 100으로 나눠 백분율로 변환한다. 9273은 92.73%, 9999는 99.99%다.
매칭률 열이 존재하는데 값이 비었거나 음수, 100 초과, NaN 등일 경우 접수 단계에서 거절한다.
명시적 logType이 있으면 이를 우선하며 점수로 재분류하지 않는다.
`답변확률`, `labelMatchProbability`, 질의 유효 여부는 이 정책의 점수 열로 사용하지 않는다.

```csv
번호,질문,날짜,keywordMatchPercent
1,운행 시간 문의,2026-03-01 00:31:52,24.99
2,환승 문의,2026-03-01 00:32:00,25
3,승차권 문의,2026-03-01 00:33:00,74.99
4,역 위치 문의,2026-03-01 00:34:00,75
```

유형별 건수, 일별 통계, 미답변율, 추이, 군집 좌표의 logType 모두 같은 분류 함수를 사용한다.
BE는 백분율 형식을 검증하고 AI가 계산한 분류 및 집계 결과를 기존 콜백으로 저장한다.

## 제공된 원본 chatting_log CSV

원본 CSV/XLSX를 기존 업로드 화면에 그대로 올리면 된다. 별도 변환 도구를 실행할 필요가 없다.
BE의 AnalysisUploadReader가 원본 양식을 감지해 AI 입력을 자동 정규화한다.
AI의 직접 CSV 업로드 API와 배치 실행 경로도 같은 양식과 문자 인코딩을 자동 인식한다.

- `kind=1`인 응답 행만 추출한다. `kind=0`을 별도의 미답변으로 세지 않는다.
- `seq_num` → `번호`, `msg_m` → `질문`, `sysdate` → `날짜`로 옮긴다.
- `msg_m_txt`가 아닌 사용자의 원래 질문을 보존한다.
- 원본 점수 열 `ai_percent`를 보존하고 공통 분류 함수에서 100으로 나눈다.
- 원본에 `logType`이 있으면 그대로 보존하고 점수보다 우선한다. 없거나 빈 문자열일 때 매칭률을 사용한다.
- CP949 원본도 자동으로 읽어 내부 AI 입력은 UTF-8로 통일한다.
- 사용자가 올린 원본 파일은 기존 보관 경로에 그대로 저장한다. 자동 정규화는 AI 전송용 사본에만 적용한다.
- 오류의 행 번호는 질문 행 필터/CSV 재생성 이후에도 원본 CSV/엑셀 행 번호를 가리킨다(BE).

기존 분석용 양식에는 원본용 kind 필터를 적용하지 않는다. 학습용 라벨 등 기존 열도 보존한다.
원본과 분석용 필수 열이 불완전하게 혼합되어 모호한 경우에는 임의로 추측하지 않고 거절한다.

`chatting_log_day`는 날짜별 집계 파일이다. 개별 질문과 매칭률이 없으므로 FAQ 분석 업로드 대상이 아니다.
해당 파일의 answer_cnt에서 오답변 수를 역산하지 않는다.
