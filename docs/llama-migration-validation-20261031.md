# Llama 전환 로컬 검증 — 2026-10-31

이 문서는 모델 승인 전 소형 모델 검사 기록이다. 이후 공식 8B 다운로드·실행 및 수정 결과는
[Llama 3.1 8B 실행·호환성 검증](llama31-8b-execution-20261031.md)을 우선 참고한다.

## 범위와 판정

최종 회귀: unittest 84개 실행, 83개 통과·1개 건너뜀. 기존 API/작업 상태/검색 근거/
클러스터링/DB 모의 회귀와 새 모델 선택·EOT·컨텍스트·FAQ 스키마 검증을 포함한다.
로그는 `tmp/llama-final-tests.log`이다. 실제 DB 접속이나 목표 모델 성능 검증 결과는 아니다.

코드 전환 및 로컬 연결 검증 완료. 목표 Llama 3.1 8B의 실행·운영 채택은 미완료다.
현재 Vast는 사용자 요청에 따라 중지 상태를 유지한다. 로컬에 목표 8B 가중치나 Hugging Face 접근 인증이 없어 대신 보유한 소형 모델로 검증했다.
이 결과를 Qwen 7B 대 Llama 8B 비교나 정식 20문항×5조건 평가로 해석하지 않는다.

## 새로 실행한 비교

RTX 2060 6GB, 같은 입력 3개, seed=42, greedy, max_new_tokens=160, NF4 4bit.
질문/프롬프트 해시, 생성 설정의 동일성을 확인했다. 모델별 tokenizer/chat template은 각 모델의 것을 사용했다.
이전 답변/점수를 재사용하지 않았다. 아래 peak는 PyTorch 할당 메모리와 프로세스 표본 RSS다.
패키지는 torch 2.9.1+cu126, transformers 4.57.3, accelerate 1.15.0이며 배포 pin과 다르다. 배포 이미지 검증은 별도 필요하다.

| 모델 | 추론 성공 | 요청 평균(s) | 로딩(s) | CUDA peak(GiB) | RSS 표본 최대(GiB) |
|---|---:|---:|---:|---:|---:|
| Qwen2.5 3B | 3/3 | 6.19 | 36.05 | 1.98 | 4.65 |
| Llama 3.2 3B | 3/3 | 6.79 | 33.23 | 2.17 | 5.58 |

3건의 서로 다른 길이 응답에 대한 기술 통계이며 성능 우열의 통계적 근거가 아니다. 반복 부하/장시간 안정성은 미측정이다.

## 출력 검토

- 한국어 근거 답변: Llama 3B가 분실 시간·노선·방향·승하차역과 역 직원 문의를 출력했다.
- FAQ JSON: Llama는 synonyms를 누락했고 Qwen은 reason을 누락했다. 기존 정규화가 기본값을 보완한다. Llama JSON의 질문/답변 자료형은 문자열이었다.
- 수정: Llama 3B는 근거에 없는 방문시간과 개인정보 요구를 생성했다. 사실성 실패이며 운영 후보로 채택하지 않는다. 이 검사는 실제 production Refine 전체 프롬프트가 아닌 연결용 fixture다.
- 별도 1B 검사에서는 답변 반복, JSON 필드 자료형 오류 및 수정 실패가 확인됐다. 1B도 운영 모델로 채택하지 않는다.
- JSON 자료형 오류는 FAQ 검증기에서 REJECT로 처리하도록 보강했다. 자료형 검증만으로 사실성을 보장하지 않는다.
- 위 평가는 출력 수동 점검이며 담당자의 FAQ 승인율 평가가 아니다. 정량 Judge 점수나 승인율은 산출하지 않았다.

## 후속 실행 조건

1. 목표 모델 접근 승인 후 로컬 Hugging Face 로그인 또는 비밀 환경변수 설정. 토큰을 채팅·Git에 저장하지 않는다.
2. 8B를 로컬 4bit 또는 가용 GPU에서 격리 추론. OOM 여부·한국어·실제 RAG/Refine 프롬프트 확인.
3. 기존 20문항 실험은 성능 입증에서 제외한다. 대표성 있는 독립 평가셋·검증된 근거·채점 기준을 별도로 확정한 뒤 새로 생성·평가한다.
4. 담당자의 실제 승인율, 근거 밖 정보, 필수 정보, 실패율과 자원을 확인한 뒤 최종 모델 확정.
5. 운영 환경이 준비되면 BE/DB 저장·조회·관리자 승인·오류 callback E2E 확인. 라이선스/보안 승인 후 배포.
